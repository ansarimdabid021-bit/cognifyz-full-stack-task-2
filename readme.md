# 🚀 Cognifyz Full Stack Development – Task 2

## 📌 Project Overview

Yeh project **Cognifyz Full Stack Development Internship – Task 2** ke part ke roop mein develop kiya gaya hai.

Is project ka main purpose form interaction, client-side validation, server-side validation aur temporary server-side data storage ko demonstrate karna hai.

## 🎯 Task Objective

Is project mein ek interactive web form create kiya gaya hai jisme:

- User input collect kiya jata hai
- Client-side validation ki jaati hai
- Server-side validation ki jaati hai
- Valid data ko temporary server-side storage mein save kiya jata hai
- Successful submission ke baad result page display hota hai
- Invalid data ke liye error messages show kiye jaate hain

## ✨ Features

- 📝 Interactive form
- ✅ Client-side validation
- 🔐 Server-side validation
- 📧 Email validation
- 👤 Name validation
- 🎂 Age validation
- 💼 Role selection
- 🔑 Password validation
- 💬 Message validation
- 📊 Character counter
- ⚠️ Error handling
- 💾 Temporary server-side data storage
- 📄 Dynamic result page
- 📱 Responsive design
